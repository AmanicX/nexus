Common questions

Is it really uncensored?

Nexus does not filter what your characters say. The model decides, and the model you picked decides with it. Nothing is rewritten on the way back to you.

What does it cost?

Nothing. Nexus is free and open source. You bring a model key, or you run a model locally and pay nothing at all.

Which models can I use?

Anything that speaks an OpenAI style chat API. Groq or OpenRouter if you want it hosted, Ollama or LM Studio if you want it on your own machine.

Does anything leave my machine?

Only the requests you send. With a local model nothing leaves: no account, no telemetry, no server of ours to send it to.

What do I need to install it?

Windows 10 or later gets an installer. On Linux there is a .deb, an AppImage, an .rpm and a pacman package. No build step, no runtime to install first.

Where does it keep my chats?

In your own profile folder, as plain files you can read, edit or delete. Characters and world notes live beside them.

Is this made by an AI company?

No. Nexus talks to those APIs and nothing else. It is not made, endorsed or supported by any of them.
