1.2.0

Anywhere you are

Nexus left the desktop. The same studio now opens in a browser, installs to a home screen, and ships with an Android project in the repository. It was built for a thumb, not a mouse.

Built for a touch screen

Rows, buttons and sliders are sized for a finger. Anything that used to appear on hover now stays where a thumb can reach it.

An app from a browser tab

Open the web build once and add it to your home screen. It gets its own icon and opens full screen, with no store and no install file.

It keeps working offline

The shell is stored on your device, so reopening Nexus does not need a connection. Your characters, worlds and chats stay where you left them.

Nothing runs off the edge

On a phone the app fills the screen edge to edge, clears the notch and the home bar, and never scrolls the wrong way or doubles up the page.

A real Android project

The repository carries a Capacitor project with its own launcher icons and splash, so the same build can become an Android app.

A place for the history

The site gained this page: every version in order, what changed, and a direct file for each platform instead of a search through the tags.

1.1.0

Bring your own provider

Nexus stopped being a client for one company. It now talks to anything that speaks the OpenAI chat format, hosted or running on your own machine, picked from a single list.

Five providers, one screen

Groq and OpenRouter if you want it hosted. Ollama and LM Studio if you want it local. A fifth option takes any base URL you type yourself.

A live model list

Instead of a hard-coded handful, Nexus asks the provider what it serves and shows you all of it in a searchable list.

Local models stay local

Point Nexus at a model on your own machine and no request leaves your network. No account, no key, nothing to pay.

Your studio moves with you

Characters, worlds and conversations are upgraded in place the first time the new version opens. Nothing to re-enter by hand.

1.0.0

The studio, opened

The first build put the whole thing in one window: write a character, put them somewhere, and talk to them with a model you choose.

Characters

A face, a voice, a persona, a greeting. Canon figures and your own, sitting in the same list.

Worlds

Places, factions and lore, plus reputation, events and notes that survive from one turn to the next.

Six commands

Mark a thought, mark an action, hand a line to someone else, force an event, and move the world itself.

Three themes

Chatbot, Anime and World, each with its own palette and its own mood.

Memory

A rolling summary per conversation, so a long scene keeps its shape instead of drifting.

An installer, not a build

A Windows setup file and Linux packages, ready to run. Nothing to compile first.

About versions

How do the numbers work?

Three of them. The first goes up when something stops working the old way, the second for new features, and the third for fixes. 1.2.0 adds the web and Android builds on top of 1.1.0.

How do updates arrive?

The desktop app can check for a newer version on launch and install it over the old one. The web app picks up a new build the next time you open it.

Do I lose anything by updating?

No. Characters, worlds and conversations are upgraded in place the first time the new version starts.

Can I run it without installing?

Yes. Open the web app in your browser, or clone the source and run it from there.

Where does a release come from?

One tag on one commit. A build job compiles Windows and Linux from that exact source and attaches the results to the release.

Something is broken. Where do I report it?

On the project's issue tracker, with your version number and what you were doing. That is the fastest route to a fix.
